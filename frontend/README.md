# Notes App Frontend

The frontend application for the Notes App, built with React and Vite.

## Features

- React-based application structure
- Client-side routing with React Router
- Shared application layout
- Home page
- Not-found page
- ESLint configuration

## Routes

| Route | Description |
| --- | --- |
| `/` | Home page |
| `*` | Not-found page |
